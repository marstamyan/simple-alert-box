# Проверка Simple Alert Boxes 1.1.0

Дата: 12 ноября 2026 года. Исходная версия: `c60d04a`, плагин 1.0.

## Оценка функционала

Плагин решает небольшую понятную задачу: четыре вида статических информационных блоков через шорткоды, с общими настройками оформления. Для этого полноценная библиотека, собственные таблицы базы данных и JavaScript не требуются. Существующая небольшая архитектура сохранена.

Это не система всплывающих уведомлений: закрытие сообщений, расписания, пользовательские условия показа и динамические объявления не предусмотрены. Для заявленной задачи такой объём функционала достаточен.

## Обнаруженные проблемы и исправления

| Проблема исходной версии | Исправление |
| --- | --- |
| Жирный текст, ссылки и HTML вложенных шорткодов показывались как текст с тегами | Разрешён безопасный HTML записей WordPress; результат вложенных шорткодов фильтруется через `wp_kses_post()` |
| Несколько абзацев после обработки классическим редактором давали незакрытые теги `<p>` | Нормализована обработка абзацев; проверяется баланс тегов |
| Пустой шорткод передавал `null` в строковые функции WordPress | Отсутствующее содержимое превращается в пустую строку |
| Неверный или пустой цвет сохранялся и оставлял пустое CSS-правило | Неверное изменение отклоняется с сообщением; сохраняется прежнее допустимое значение |
| Массив вместо цвета вызывал `TypeError` в PHP 8 | Тип значения проверяется до вызова функции обработки цвета |
| `intval()` принимал отрицательные размеры, массивы, дроби и строки наподобие `12px` | Проверяются тип, целочисленный формат и диапазон для каждого поля |
| Старые некорректные значения в базе обходили значения по умолчанию | Все настройки проверяются и при чтении; испорченные значения получают рабочие значения по умолчанию без миграции |
| Стили выводились непосредственно через `wp_head`, а на странице настроек отсутствовали | Использованы стандартные функции подключения стилей; в админке они подключаются только на странице плагина |
| Поля формы не имели связанных подписей и подсказок | Добавлены `label`, идентификаторы, описания формата и допустимые границы |
| Интерфейс не был подготовлен к переводу | Добавлены переводимые строки и согласованный домен `simple-alert-box`; файлы перевода не включены |
| Контраст стандартного текста к фону составлял примерно 3,61–4,47:1 | Стандартные цвета текста затемнены; для всех четырёх пар автоматически проверяется минимум 4,5:1 |

Пределы: внутренний и внешний отступы — 0–1000 px, размер текста — 1–200 px. Допустимы цвета `#RGB` и `#RRGGBB`. Нулевые отступы работают.

Имена четырёх шорткодов, CSS-классы, адрес страницы настроек и имена всех одиннадцати опций сохранены. Корректные пользовательские настройки, включая выбранные цвета, не заменяются.

## Проверки

Интеграционные проверки выполняются на настоящем WordPress с MariaDB 10.11, без подмены функций WordPress:

| Окружение | Результат |
| --- | --- |
| WordPress 6.0 / PHP 7.4.14 | 385 проверок прошли |
| WordPress 7.1.4 / PHP 8.3.36 | 385 проверок прошли |
| WordPress 7.1.4 / PHP 8.5.12 | 385 проверок прошли |

Проверены все четыре шорткода, пустые сообщения, Unicode, ссылки, вложенные шорткоды, небезопасный HTML, абзацы, все одиннадцать настроек, граничные и ошибочные значения, испорченные старые опции, CSS, доступ администратора и отказ подписчику. Отдельные проверки контролируют контраст стандартной палитры.

Через HTTP дополнительно прошли 67 проверок: вход администратора, открытие формы, сохранение всех настроек через `options.php`, отклонение неверных значений с сохранением прежних, отказ с HTTP 403 при отсутствующем и поддельном nonce, отсутствие стилей плагина на другой странице админки, вывод всех четырёх блоков на публичной странице. Проверялась полученная HTML-разметка; отдельный визуальный прогон браузера не выполнялся.

Официальный WordPress Plugin Check 2.2.0 проверил файлы установочной сборки: замечаний не обнаружено. Это статическая проверка; её результат дополняет функциональные тесты. Дополнительно проверены синтаксис PHP и отсутствие ошибок оформления изменений Git.

На PHP 8.5 инструмент WP-CLI 2.12.0 выводит собственное предупреждение `Deprecated` из `php-cli-tools/lib/cli/Colors.php`. Оно находится вне плагина; функциональные проверки проходят. Подавление таких предупреждений в код плагина не добавлялось.

Автоматическая проверка для GitHub Actions добавлена, но в самом GitHub ещё не запускалась. Результаты выше получены локально. Инструкции повторного запуска находятся в `tests/README.md`.

## Безопасность и ограничения

В исходной версии уже использовались стандартные защитные поля Settings API и право `manage_options`. Эксплуатируемых CSRF или XSS при этой проверке не найдено. Новые проверки типов и ограничение допустимого HTML усиливают устойчивость к некорректным данным; это не обещание отсутствия всех возможных уязвимостей.

Внутри блоков поддерживается HTML, разрешённый WordPress для записей. Встраивания с `iframe`, скрипты и другие запрещённые элементы отбрасываются. Вложение одинакового типа шорткода внутрь самого себя ограничено стандартным парсером WordPress.

Пользовательские цвета и стили темы могут менять контраст. Проверки стандартной палитры не означают полного соответствия всего сайта требованиям доступности. Сочетания со всеми сторонними темами и плагинами не проверялись. Данные настроек сохраняются при деактивации и удалении плагина.

Для действующего сайта следует использовать поддерживаемые версии WordPress и PHP. Проверка старого окружения подтверждает совместимость плагина, а не пригодность старых версий для эксплуатации.

## Сборка

Версия: 1.1.0. Архив: `dist/simple-alert-box-1.1.0.zip`. В него включены только файлы плагина и инструкции; тесты, Git, временные установки WordPress и локальные учётные данные исключены.

Обновление существующей установки: замените файлы в прежнем каталоге плагина. Отчёт описывает локальную проверку. Отправка изменений в GitHub и публикация релиза выполняются отдельно.

## Доработки версии 1.2.0 — 13 ноября 2026 года

Добавлены единый шорткод `mk_alert` с параметрами `type`, `title`, `icon`, необязательные заголовки и значки для прежних шорткодов, стандартная палитра WordPress, предпросмотр четырёх типов сообщений и предупреждения о недостаточном контрасте. Прежние шорткоды без параметров сохраняют свой вид. Имена всех одиннадцати настроек сохранены.

Изменения в предпросмотре не сохраняются автоматически. Настройки применяются через прежнюю защищённую форму. JavaScript подключается только на собственной странице настроек, дополнительные скрипты на публичных страницах не требуются. Значки имеют текстовый эквивалент для программ чтения с экрана.

В каждом окружении WordPress 6.0 / PHP 7.4.14, WordPress 7.1.4 / PHP 8.3.36 и WordPress 7.1.4 / PHP 8.5.12 успешно прошли 428 интеграционных проверок. Сборка проверена WordPress Plugin Check 2.2.0 без замечаний; синтаксис PHP и JavaScript проверен отдельно.

В браузере проверены выбор образца из палитры, ручной ввод HEX, восстановление цвета по умолчанию, обновление отступов, предупреждение при контрасте 1:1, отсутствие автоматического сохранения, сохранение через кнопку и подтверждение результата. На публичной странице проверены все четыре типа с заголовками и значками, ссылки, форматирование и прежний вид старого шорткода. Порядок повторной проверки описан в `tests/README.md`.

Архив новой версии: `dist/simple-alert-box-1.2.0.zip`. Блок для визуального редактора, закрытие сообщений и индивидуальные размеры блоков в этот этап не входят.
